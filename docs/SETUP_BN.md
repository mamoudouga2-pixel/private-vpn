# সেটআপ গাইড (ফোন থেকে, ধাপে ধাপে)

## কী কী লাগবে
- পাঁচটা সার্ভার (উবুন্টু ২২.০৪ বা ২৪.০৪, প্রতিটার নিজস্ব পাবলিক আইপি): অস্ট্রেলিয়া, আর্জেন্টিনা, মেক্সিকো, ব্রাজিল, নিউজিল্যান্ড
- একটা ডোমেন
- ফোনে Termux অ্যাপ
- অ্যাপ বানানোর জন্য একটা গিটহাব অ্যাকাউন্ট

**মনে রাখুন:** ২০টা শহর আসলে লেবেল। সার্ভার আছে ৫টা। শহর বাছলেও ইউজার সেই দেশের সার্ভারের আইপি পাবে।

## ধাপ ১: ডোমেন ঠিক করুন
ডোমেনের ডিএনএস পাতায় একটা "এ রেকর্ড" দিন। নাম `vpn`, মান হবে কন্ট্রোল সার্ভারের আইপি। (কন্ট্রোল সার্ভার = পাঁচটার যেকোনো একটা। যেটা সবচেয়ে ভালো চলে সেটা নিন।)

## ধাপ ২: ফোন থেকে কন্ট্রোল সার্ভারে জিপ তুলুন
Termux-এ:
```
termux-setup-storage
scp ~/storage/downloads/PRIVATE_VPN.zip root@কন্ট্রোল-আইপি:/root/
ssh root@কন্ট্রোল-আইপি
```
(`scp` একবার পাসওয়ার্ড চাইবে, `ssh` আরেকবার।) এখন সার্ভারের ভেতরে:
```
passwd
apt-get update && apt-get install -y unzip
unzip PRIVATE_VPN.zip
cd NovaVPN_Private_Network_MVP
```
`passwd` দিয়ে নতুন পাসওয়ার্ড দিন।

## ধাপ ৩: কন্ট্রোল অংশ বসান
```
bash server/control/install_control_plane.sh
```
ডোমেন আর ইমেইল জিজ্ঞেস করবে। শেষে `https://ডোমেন/health` খুলে `ok` দেখলে ঠিক আছে।

## ধাপ ৪: পাঁচ দেশের সার্ভার বসান
একই জায়গা থেকে:
```
bash server/deploy_nodes.sh
```
প্রতিটা দেশের আইপি দেবেন। প্রতিটা সার্ভারের পাসওয়ার্ড একবার করে চাইবে। যে সার্ভারে আছেন সেটার জন্য "same machine" প্রশ্নে `y` দিন। শেষে পাঁচটা সার্ভারের অবস্থা দেখাবে, সবগুলোর পাশে `OK` থাকলে ঠিক আছে।

প্রতিটা সার্ভারের ফায়ারওয়ালে (হোস্টিংয়ের প্যানেলে) খুলে রাখুন: `22` (টিসিপি), `51820` (ইউডিপি)। কন্ট্রোল সার্ভারে আরও `80` ও `443` (টিসিপি)।

## ধাপ ৫: ইউজার বানান
```
novavpn-admin add-user rahim rahim@example.com
```
এটা সাথে সাথে পাঁচ দেশেরই চাবি বানিয়ে ফেলবে এবং একটা অস্থায়ী পাসওয়ার্ড দেখাবে। সেটা ইউজারকে দিন। প্রথমবার ঢুকে ইউজার পাসওয়ার্ড বদলাবে।

## ধাপ ৬: অ্যাপ বানান
`docs/GITHUB_BN.md` দেখুন। গিটহাবে প্রজেক্ট তুলে অ্যাকশন চালালে APK পাবেন। অ্যাপে ঢোকার সময় "PRIVATE NETWORK ADDRESS" ঘরে `https://vpn.আপনার-ডোমেন.com` দেবেন।

## ধাপ ৭: পরীক্ষা (ইউজার দেওয়ার আগে করুন)
১. নিজের ফোনে অ্যাপ বসিয়ে প্রতিটা দেশ একবার করে চালু করুন।
২. ব্রাউজারে "what is my ip" খুঁজে দেখুন আইপি সেই দেশের কি না।
৩. ইউজার বন্ধ করে দেখুন সংযোগ কেটে যায় কি না।
৪. অ্যাপের Settings থেকে Android VPN settings খুলে "Always-on VPN" আর "Block connections without VPN" চালু করুন।

## রোজকার কমান্ড (কন্ট্রোল সার্ভারে)
| কাজ | কমান্ড |
|---|---|
| সবার তালিকা | `novavpn-admin list-users` |
| ইউজার বন্ধ | `novavpn-admin disable rahim` |
| আবার চালু | `novavpn-admin enable rahim` |
| ইউজার মুছুন | `novavpn-admin delete rahim` |
| পাসওয়ার্ড রিসেট | `novavpn-admin reset-password rahim` |
| সার্ভার ঠিক আছে কি না | `novavpn-admin servers` |
| বাদ পড়া চাবি আবার মোছা | `novavpn-admin retry-revocations` |
| গণনা | `novavpn-admin summary` |

কোনো সার্ভার বন্ধ থাকলে ইউজার বন্ধ করার সময় সেটার চাবি মোছা বাকি থাকে। সার্ভার ফিরলে `retry-revocations` চালাবেন।

## এখনো যা পরীক্ষা হয়নি
- অ্যাপ বানিয়ে আসল ফোনে চালানো
- আইপিভি৬ লিক (সার্ভার আইপিভি৬ ফেলে দেয়, তাই লিক হওয়ার কথা নয়, কিন্তু ফোনে পরীক্ষা করুন)
- ৫০-৬০ জন একসাথে চালানো
- টাকা নেওয়ার ব্যবস্থা, আইফোন অ্যাপ

## পরে কোনো শহরের জন্য আলাদা সার্ভার এলে
এখন ২০টা শহর নিজের দেশের সার্ভার ব্যবহার করে। পরে সিডনির জন্য আলাদা সার্ভার পেলে (কোড দেখতে `novavpn-admin locations` চালান):
```
bash server/deploy_nodes.sh au-sydney
novavpn-admin provision-all
```
- প্রথম কমান্ড নতুন সার্ভারে ভিপিএন বসাবে আর ঠিকানা সেভ করবে।
- দ্বিতীয় কমান্ড সব ইউজারকে ওই সার্ভারের চাবি দেবে।
- এরপর থেকে ইউজার "Sydney" বাছলে নতুন সার্ভারে যাবে। বাকি তিন শহর আগের মতো দেশের সার্ভারেই থাকবে।
- নতুন ইউজার বানালে চাবি নিজে নিজেই সব সার্ভারের জন্য তৈরি হবে।
- অ্যাপ বা ইউজারের কিছু বদলাতে হবে না। অ্যাপ প্রতিবার সংযোগের সময় নতুন চাবি নামায়।
